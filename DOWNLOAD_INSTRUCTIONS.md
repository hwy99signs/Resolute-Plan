## 📲 Installation Steps

1. **Open the link** on your Android phone using Chrome browser
   
2. **Download the APK file** when prompted

3. **Enable installation from unknown sources** (if needed):
   - Go to **Settings** → **Security** → **Install unknown apps**
   - Select your browser (Chrome) → Enable "Allow from this source"
   - OR when you tap the downloaded APK, Android will prompt you to allow installation

4. **Install the app**:
   - Tap the downloaded APK file
   - Tap "Install"
   - Wait for installation to complete
   - Tap "Open" to launch the app
